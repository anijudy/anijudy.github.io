# Yifan Zhao Academic Website

Bilingual academic website for Yifan Zhao, focused on single-cell genomics,
host-pathogen interactions, cell-type deconvolution, and cross-species studies.

## Local preview

Open `index.html` directly in a browser. The site is self-contained and does not
require a build step.

## GitHub Pages

Publish this repository as `anijudy.github.io` from the `main` branch.
