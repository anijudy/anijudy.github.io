Academic Profile

Selected Research

Dual single-cell host–pathogen analysis

CIQI Lab · 2025–2026

Analyzing single-cell data in which host and intracellular bacterial transcripts are captured from the same infected cells. The work evaluates bacterial-read reliability, benchmarks integration strategies, and examines whether aggregation and time-aware analysis can make sparse interaction signals interpretable.

Reference matching in cell-type deconvolution

Briefings in Bioinformatics · 2026

Compared six deconvolution methods across matched and mismatched single-cell references. The study showed that method choice was often more consequential than reference matching, providing practical guidance for estimating cell composition from bulk RNA-seq.

Cross-species genome annotation

CIQI Lab · 2025–2026

Using TOGA orthology inference to improve guinea pig genome annotation, then evaluating how the revised annotation changes gene recovery and biological interpretation in single-cell RNA-seq data.
